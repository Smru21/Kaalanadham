Smart Bell User Guide
Everything you need to know about your Smart Bell system
🚀
Getting Started
▶

Smart Bell is an automatic school bell system that rings bells at scheduled times. It replaces manual bell ringing with a reliable, programmable device.

How it works:

  • Schedule events — set bell times for each day of the week
  • Choose tracks — assign different music/ringtones to each event
  • Set holidays — mark dates when bells should be silent
  • Save templates — switch between schedules (regular, exam, half day)
  • Manual control — ring bells or make live announcements anytime

Two ways to control:

  • This web app — full control from any phone/computer on the same WiFi
  • Physical buttons — navigate menus, ring bells, and reset directly on the device

💡 Tip: The device works 100% offline. WiFi is only needed for automatic time sync (NTP).

📅
Schedule & Events
▶

An event is a scheduled bell ring. Each event has:

FieldDescription
NameLabel shown on display (e.g. "Recess", "Period 3")
TimeHour and minute when the bell rings
DaysWhich days of the week (Mon-Fri, Sat, Sun)
TrackMusic file to play from SD card

Adding an event:

  • Go to Schedule tab
  • Enter name, time, select days, and choose a track
  • Tap Add Event

Managing events:

  • Toggle switch — enable/disable without deleting
  • ✕ button — permanently delete an event
  • Clear All — remove all events at once

💡 Maximum 100 events can be scheduled. Disabled events remain saved but won't ring.

Track selection: Tap the track field to open a searchable dropdown. Tracks come from the SD card. Sync track names from the desktop app for easy identification.

📋
Schedule Templates
▶

Templates let you save and switch between entire schedules with one tap.

Example templates:

  • Regular Day — 15 events, full school day (Mon-Fri)
  • Saturday — 8 events, half day schedule
  • Exam Day — 4 events, exam timings only
  • Sports Day — custom event schedule

How to use:

  • Set up your schedule normally (add all events)
  • Go to Schedule Templates section
  • Enter a name and tap Save Current Schedule
  • Later, tap Load to restore that schedule

⚠️ Loading a template replaces all current events. Save your current schedule as a template first if you want to keep it.

Maximum 10 templates can be stored.

🏉
Holiday Calendar
▶

Mark dates when all bells should be completely silent.

Use for:

  • Public holidays (Christmas, Diwali, Independence Day)
  • School vacations
  • Exam days (if no bells needed)
  • Staff meetings / special occasions

How it works:

  • Add a date and optional name
  • On that date, all scheduled events are automatically skipped
  • The home screen and TFT display show "Holiday" status
  • Manual bell and live announcements still work on holidays

Past holidays appear faded. Today's holiday shows a TODAY badge. Maximum 50 holidays.

🎮
Manual Bell & Live Announcements
▶

Manual Bell:

  • Ring any ringtone instantly from Controls tab or the PLAY button on device
  • Choose from 10 ringtones stored on the SD card
  • All scheduled events are paused while ringing
  • Tap again or press Stop to end

Live Announcement:

  • Activates the MEMS microphone for real-time PA
  • Your voice is streamed through the speaker instantly
  • All scheduled events are paused during live mode
  • Start/stop from web UI or device buttons

Audio Path:

ModeSignal Path
Scheduled/ManualSD Card → DFPlayer → Amplifier → Speaker
Live AnnouncementMicrophone → ESP32 → DAC → Amplifier → Speaker

A relay physically switches between audio sources. The amplifier has a 100ms warmup delay for clean audio.

📶
WiFi & Time Sync
▶

Two WiFi modes:

ModeDescription
AP Mode (default)Device creates "SmartBell" WiFi. Connect your phone directly. Always available at 192.168.4.1
Station ModeDevice connects to your router. Enables internet access for NTP time sync. AP stays active as fallback.

Connecting to WiFi:

  • Go to Settings → WiFi Settings
  • Tap Scan Networks (may need to tap twice)
  • Select your network and enter the password
  • The device connects and starts NTP time sync

NTP Time Sync:

  • Automatic sync every 6 hours when WiFi is connected
  • Uses pool.ntp.org as primary server
  • Can be triggered manually from WiFi settings
  • Timezone: IST (UTC+5:30) — configured in firmware

Auto-Reconnect: If WiFi drops, the device automatically attempts to reconnect with exponential backoff (30s → 60s → 120s → max 5min). AP mode always remains accessible.

💡 Tip: WiFi is completely optional. The device keeps time with its battery-backed RTC and works 100% offline.

Backup & Restore
▶

Backup downloads all your settings as a single JSON file:

  • All scheduled events
  • School name, theme, colors
  • Holiday calendar
  • Sound name mappings
  • PIN code

Restore uploads a backup file and replaces all current settings. Useful for:

  • Recovering after factory reset
  • Transferring settings to a new device
  • Keeping a safe copy before making changes

⚠️ Restore replaces everything. Download a backup first if you want to save current settings.

💡 Tip: Sound names are preserved during factory reset since they're tied to the SD card contents.

Security & Reset
▶

PIN Protection:

  • Default PIN: 1234
  • Must be 4-8 characters
  • Required to access the web UI
  • Change in Settings → Password Protection

PIN Reset (if you forget it):

MethodHow
Button ComboPress NEXT → OK → MENU (each within 500ms). 10-second countdown. Press PLAY to cancel.
Serial CommandConnect USB, open terminal at 115200 baud, type resetpassword

Factory Reset (erases everything except sounds and backgrounds):

MethodHow
Button ComboPress PLAY → MENU (within 500ms). 10-second countdown. Press NEXT or OK to cancel.
Serial CommandType factoryreset YES
Web APIPOST to /api/factoryreset

What factory reset deletes: Events, WiFi credentials, school name, theme, colors, PIN, holidays, templates, setup wizard flag.

What factory reset preserves: Sound name mappings, background images.

💡 Both button combos have a 10-second boot guard — they're ignored for the first 10 seconds after power on.

Troubleshooting & FAQ
▶
QBell is not ringing at scheduled times▶
Check these in order:
1. Is the event enabled? (toggle switch should be green)
2. Is today's weekday selected?
3. Is today a holiday?
4. Is the scheduler running? (Home tab status)
5. Is the time correct?
6. Is the SD card inserted with audio files?
7. Check System Log for errors.
QCan't connect to Smart Bell from my phone▶
1. Connect to "SmartBell" WiFi (password: bell1234)
2. Open browser → 192.168.4.1
3. Disable mobile data temporarily if phone auto-switches
4. On iPhone: tap Use Without Internet if prompted
5. In station mode, use the router IP from WiFi status
QTime is wrong or resets after power loss▶
Quick fixes:
1. Settings → Date & Time → Sync Phone Time → Save
2. Or connect WiFi for NTP sync

If time resets after power loss: The RTC backup battery (CR2032) may be dead. Replace it.
QForgot PIN / Locked out▶
Press NEXT → OK → MENU on the device (each within 500ms). Wait 10 seconds. PIN resets to 1234.

Or connect USB and type resetpassword in serial terminal.
QNo audio / speaker not working▶
1. Check DFPlayer status in Home → System Status
2. Verify SD card is inserted (FAT32, files named 0001.mp3, 0002.mp3...)
3. Check amplifier power (GPIO 5)
4. Try serial command dftest
5. Check relay (GPIO 4)
QTrack names not showing▶
Track names must be synced from the desktop app. The DFPlayer only knows files by number. Without the desktop app, tracks show as "Track 1", "Track 2", etc. This doesn't affect bell functionality.
QWiFi keeps disconnecting▶
Auto-reconnect handles this automatically (backoff: 30s → 60s → 2min → max 5min).

If persistent: Move device closer to router. TX power is limited to 2dBm to prevent audio noise. AP mode at 192.168.4.1 always works.
QLive announcement has echo▶
Speaker and mic are in the same enclosure. Point speaker away from mic, reduce volume, speak close to microphone.
QHow to install as a phone app▶
Android: Chrome menu (⋮) → "Add to Home Screen"
iPhone: Safari Share (⬆) → "Add to Home Screen"
Desktop: Address bar install icon

Opens full-screen like a native app. Still requires WiFi to the Smart Bell device.
QHow to use serial debug commands▶
Connect USB. Open serial terminal at 115200 baud.

Commands: time, date, settime, events, bell, stop, live, dftest, status, clear, logs, wifi, wifitest, ntp, resetpassword, showpassword, factoryreset YES, help
